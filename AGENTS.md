# Agent instructions

This repository is commercial device software: an Ubuntu golden image
plus a chat UI. The owner talks to the assistant; the assistant
administers the machine. They should not have to understand Ubuntu.

Start with `CLAUDE.md`. Then load the matching skill from
`.claude/skills/` before you change that area (`taskmd`,
`golden-image`, `agentic-ui`, `tauri-nuxt`, `product-ux`,
`commercial-hygiene`, `hermes-gateway-client`, `brain-contract`).
Those skills are for coding agents only and are not copied onto the
device.

Owner-facing agent skills stay in `brain/skills/`.
