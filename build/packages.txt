# Every apt package baked into the golden image.
#
# This file is the equivalent of a declarative system package list: the
# device installs nothing at first boot, so anything missing here is
# missing on the shipped unit. Blank lines and #-comments are ignored.
#
# Keep entries grouped and justified. Each package costs image size, and
# the image is copied byte-for-byte onto every unit.

# --- base system ---------------------------------------------------------
# Booting, networking and time on a machine with no keyboard and no admin.
linux-image-generic
systemd-sysv
systemd-timesyncd
network-manager
ca-certificates
sudo
locales
# Intel microcode + redistributable firmware: without these the mini-PC
# tier has ethernet only, and no wifi at the customer site.
intel-microcode
linux-firmware
# EFI bootloader. The image ships a GPT with an ESP, so the installed
# system must be able to boot itself after a raw block copy.
grub-efi-amd64
grub-efi-amd64-signed
shim-signed
efibootmgr

# --- desktop -------------------------------------------------------------
# Ubuntu's own desktop session, used as shipped: GNOME, GDM, PipeWire,
# portals, polkit, fonts and the whole application stack come with it.
# The assistant runs as an ordinary autostarted app on top rather than
# replacing the session.
ubuntu-desktop

# --- filesystem / install tooling ---------------------------------------
# Needed on the device itself, not just the installer: the first-boot
# unit grows the root filesystem to fill whatever disk the unit shipped
# with, since one image serves several storage variants.
cloud-guest-utils
e2fsprogs
dosfstools
parted
gdisk
util-linux

# --- GUI shell runtime ---------------------------------------------------
# The Tauri binary is built elsewhere with the system toolchain and
# copied in. These are the shared libraries it links against; on a normal
# FHS distro they are all it needs -- no interpreter or RPATH rewriting.
# Most are pulled in by ubuntu-desktop already; named explicitly so a
# change to that metapackage cannot silently break the shell.
#
# The t64 suffixes are not typos: those libraries were renamed by the
# 64-bit time_t transition, and the unsuffixed names no longer exist.
libwebkit2gtk-4.1-0
libgtk-3-0t64
libcairo2
libgdk-pixbuf-2.0-0
libglib2.0-0t64
glib-networking
libdbus-1-3
libssl3t64
librsvg2-2
librsvg2-common
libatk-bridge2.0-0t64
libatk1.0-0t64
libharfbuzz0b
libsoup-3.0-0
libpango-1.0-0
# The shell stores the cloud key in the OS keyring, which needs a daemon
# running -- without this, saving a key fails loudly rather than
# degrading to insecure storage.
gnome-keyring
libpam-gnome-keyring

# --- fonts ---------------------------------------------------------------
# Several supported languages need non-Latin scripts, and the UI relies
# on the system font stack rather than a bundled webfont. CJK is a
# separate, much larger package split out upstream on purpose, so it is
# named here rather than assumed.
fonts-noto
fonts-noto-cjk
fonts-noto-color-emoji

# --- device services -----------------------------------------------------
# The agent-facing metadata for these lives in registry/*.yaml.
postgresql
postgresql-client
redis-server
# Docker is part of the shipped device tooling; the owner is added to the
# docker group below so ordinary container workflows do not require sudo.
docker.io

# --- local inference -----------------------------------------------------
# llama.cpp: the low tier's inference engine, and the fallback everywhere.
# `llama-server` speaks the OpenAI-compatible API the agent already knows,
# so a device with no cloud key and a single GGUF file is still useful.
#
# Distro-packaged rather than vendored: it links against the system's
# libggml/libllama, which is a fraction of the size of a bundled build and
# gets security updates with everything else.
#
# Ollama is NOT here -- it is not in the archive and installs from an
# upstream tarball instead. See scripts/install-inference.sh.
llama.cpp
llama.cpp-tools
# Vulkan backend: uses the iGPU on the mini-PC tier without dragging in
# the CUDA stack. Absent hardware makes it a no-op, so it is safe to ship
# on every unit.
libggml0-backend-vulkan
mesa-vulkan-drivers
vulkan-tools

# --- agent runtime dependencies -----------------------------------------
# Required by the hermes installer and at runtime. Listed here rather
# than left to the installer's own apt calls so the image build is the
# single place packages enter the system.
git
curl
python3
python3-venv
python3-dev
python-is-python3
ripgrep
ffmpeg
build-essential
cmake
libffi-dev
procps
openssh-client
xz-utils
# tar --zstd shells out to this binary rather than linking a library, so
# unpacking a .tar.zst fails without it even though tar claims support.
zstd

# --- developer/agent tooling --------------------------------------------
# The agent administers this device and needs a working editor and VCS.
vim
less
jq
